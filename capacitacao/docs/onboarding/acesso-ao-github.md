## Para que serve

**GitHub** (para quem mexe com código e dados): os repositórios do Gov Hub. Todo código do projeto é aberto e fica na organização GovHub-br.

## Como fazer

1. Confira se você abre: [Abrir o GitHub](https://github.com/GovHub-br).
2. Para contribuir, peça para incluírem o seu usuário na organização GovHub-br.

Quando terminar, clique em **Concluir e avançar**.
