## Para que serve

**GitHub** (para as áreas técnicas, como infraestrutura e dados): os repositórios do Gov Hub. Todo código do projeto é aberto e fica na organização GovHub-br.

## Como fazer

1. Abra a [organização GovHub-br no GitHub](https://github.com/GovHub-br) e navegue pelos repositórios.
2. Para entender como os repositórios se organizam e como contribuir, veja o [roteiro de onboarding técnico](https://gov-hub.io/documentacao/onboarding/roteiro/). Esse roteiro é **essencial** para quem é das áreas técnicas: leia com atenção antes de começar a contribuir.

Quando terminar, clique em **Concluir e avançar**.
